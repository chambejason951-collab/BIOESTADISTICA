# Ejecución del plan de 14 puntos

| Punto | Resultado concreto |
|---|---|
| 1. Alcance | Ocho escenarios, 24 variantes y nueve casos centrales. |
| 2. Auditoría del original | Precisiones de títulos, supuestos, efectos y unidades documentadas. |
| 3. Ejercicios centrales | Hemoglobina, una prevalencia y dos prevalencias independientes. |
| 4. Variantes | Cambios de dirección, potencia, diferencia o variabilidad según el escenario. |
| 5. Estructura de solución | Enunciado, fundamento, hipótesis, cálculo, código, resultado y pregunta de comprensión. |
| 6. LaTeX y PDF | Tutorial completo de 33 páginas, compilado localmente con autorización del usuario. |
| 7. QMD | Práctica y tutorial ejecutables, ambos con HTML generado. |
| 8. Verificación numérica | 24 casos, potencia en n y n − 1, parametrización y lectura de n. |
| 9. GitHub | Carpeta TAREA2 organizada con README, fuentes, código y entregables. |
| 10. Diseño visual | Horizontal 16:9; azul oscuro, azul, grises y blanco. |
| 11. Guion | Portada, dos láminas por variante central y cierre: 20 en total. |
| 12. Exportación | 20 PNG de 1920 × 1080 y PDF idéntico del carrusel. |
| 13. Publicación preparada | Texto del post, enlace de GitHub y PDF con texto e imágenes. |
| 14. Control de entrega | Cifras, ejecución, composición, enlaces e inventario comprobados. |

La publicación en LinkedIn queda a cargo del autor, conforme a su solicitud de recibir las imágenes y el texto que debe colocar en el post. La publicación de los archivos en GitHub se verifica mediante el repositorio y su commit.
